# Физика — тренажёр к добору

Интерактивный тренажёр по теории физики (1 курс, 2 семестр): механика, колебания, волны, МКТ, термодинамика, статистическая физика, явления переноса, реальные газы.

## Режимы

- **Добор (10+10)** — экзаменационный режим: 10 случайных теоретических + 10 задач, подсчёт баллов.
- **Определения** — словесные вопросы: определения, понятия, «что НЕВЕРНО», «какие утверждения верны».
- **Формулы** — вопросы на формулы и числа: константы, связи величин, формулы.
- **Задачи** — задачи в 1–3 действия с числовой проверкой ответа, подсказкой и полным решением.
- **Всё вместе** — смешанная колода из теории и задач.

## Уровни сложности

- **Лёгкий** — прямые вопросы на определения и формулы (197 теория + 90 задач).
- **Средний** — вопросы «на понимание»: почему, чем отличается, следствия законов (83 теория + 30 задач).
- **Сложный** — ловушки: «что НЕВЕРНО», похожие формулы, варианты сбалансированы по длине (149 теория + 60 задач).
- **Экзамен** — задания из нескольких утверждений по одной теме («верны 1, 2 и 4») + многошаговые задачи (29 теория + 22 задачи).

Уровни включаются галочками (можно выбрать несколько или все) и работают в том числе в режиме «Добор».

## Фильтры

- **По типу** — вкладки Определения / Формулы / Задачи / Всё вместе.
- **По сложности** — галочки Лёгкий / Средний / Сложный / Экзамен.
- **По темам** — кнопка «Темы»: галочками выбираются нужные темы, ненужные можно исключить (выбор запоминается отдельно для каждого режима).

## Справка по теме

У каждого вопроса есть кнопка **📚 Справка** — простое объяснение темы «для тех, кто открыл физику вчера» + таблица всех ключевых формул с расшифровкой букв. Кнопка **📚 Шпаргалка** вверху показывает справки сразу по всем 12 темам.

## Запуск

Открыть `index.html` в браузере или поднять локальный сервер:

```bash
python -m http.server 8000
```

и открыть http://localhost:8000

## Файлы

- `index.html` — разметка
- `style.css` — стили
- `app.js` — логика тренажёра
- `data.js` — лёгкий банк вопросов и задач
- `data_extra.js` — дополнение к лёгкому и сложному банкам
- `data_med.js` — средний уровень
- `data2.js` — сложный банк
- `data_exam.js` — экзаменационный уровень
- `data3.js` — справки по темам
