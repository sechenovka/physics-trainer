# Физика — тренажёр к забору

Интерактивный тренажёр по теории физики (1 курс, 2 семестр): механика, колебания, волны, МКТ, термодинамика, статистическая физика, явления переноса, реальные газы.

## Режимы

- **Забор (10+10)** — экзаменационный режим: 10 случайных теоретических + 10 задач, подсчёт баллов.
- **Теория** — 260 вопросов с 4 вариантами ответа, подсказкой и объяснением.
- **Задачи** — 116 задач в 1–2 действия с числовой проверкой ответа, подсказкой и полным решением.

## Уровни сложности

- **Лёгкий** — прямые вопросы на определения и формулы (142 теория + 74 задачи).
- **Сложный** — варианты сбалансированы по длине, ловушки: «что НЕВЕРНО», «какие утверждения верны», похожие формулы; задачи в два действия (118 теория + 42 задачи).

Уровень выбирается в фильтре и работает в том числе в режиме «Забор».

## Запуск

Открыть `index.html` в браузере или поднять локальный сервер:

```bash
python -m http.server 8000
```

и открыть http://localhost:8000

## Файлы

- `index.html` — разметка
- `style.css` — стили
- `app.js` — логика тренажёра
- `data.js` — банк вопросов и задач
