# Физика — тренажёр к добору

Интерактивный тренажёр по конспекту теории (1 курс, 2 семестр): 458 теоретических вопросов и 202 задачи.

## Режимы

- **🎯 План** — обратный отсчёт до добора, расписание по фазам, статистика по темам (красные — слабые), кнопки «Гонять» по каждой теме.
- **🧠 Повторение (SRS)** — интервальные повторения: ошибся → карточка возвращается через ~5 вопросов; ответил верно 2 раза подряд → выучена. Крутит именно слабые места.
- **🃏 Карточки** — флэш-карты: вопрос → «показать ответ» → самооценка «знаю / не знаю».
- **Добор (10+10)** — симуляция: 10 теории + 10 задач, в конце счёт.
- **Определения / Формулы / Задачи / Всё вместе** — свободный прогон с фильтрами.

## Методы запоминания

- **Слепой режим** (чекбокс вверху) — варианты ответа скрыты, пока не нажмёшь «показать»: сначала вспоминаешь сам, потом выбираешь.
- **«Объясни сам»** (метод Фейнмана) — после ответа на теорию можно написать объяснение своими словами, проверяется по ключевым словам.
- **Статистика по темам** — на вкладке «План» видно % верных ответов по каждой теме, слабые темы помечены красным.

## Уровни сложности

Лёгкий · Средний · Сложный · Экзамен — включаются галочками в любой комбинации. Экзаменационные вопросы — несколько утверждений по одной теме, задачи многошаговые.

## Фильтры

- По типу (вкладки), по сложности (галочки), по темам (кнопка «Темы ▾» — можно исключать, запоминается для каждого режима отдельно).
- Подсказка, справка «для чайника» и полное решение — на каждой карточке.
- 📚 Шпаргалка — весь конспект формулами и простыми объяснениями.

## Запуск локально

```bash
python -m http.server 8000
# открыть http://localhost:8000
```

## Структура

- `data.js` — лёгкий банк, `data_extra.js` — расширения лёгкого/сложного, `data_med.js` — средний, `data2.js` — сложный, `data_exam.js` — экзамен, `data3.js` — справки по темам.
- `app.js` — режимы, SRS-очередь, статистика, план; `index.html`, `style.css` — разметка и тёмная тема.
- Прогресс и статистика хранятся в localStorage браузера.
